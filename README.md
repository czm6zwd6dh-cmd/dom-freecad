# Дом / FreeCAD: публичная CAD-среда

Пакетное выполнение **FreeCAD 1.1.4** на стандартном `ubuntu-24.04` GitHub Actions runner.
Публично разрешены только универсальный код и синтетические примеры. **R1 здесь не хранится и не обрабатывается.**

## Состав

Полный `architect-engineer-spds` используется ведущим агентом из актуального архива проекта.
В `vendor/architect-engineer-spds/` помещён только проверенный облачный поднабор **v0.13.0**:
построитель прямоугольных слоёв, контроль заданных пустот, резервное копирование и их тесты.
`ORIGIN.json` содержит SHA-256 исходного архива и каждого перенесённого файла. Это не копия всего скилла.
Расчётные и нормативные инструменты полного скилла не требуют запуска внутри FreeCAD.

## Что делает workflow

Проверка публичных файлов → контроль хешей поднабора → тесты Python → загрузка закреплённого FreeCAD →
синтетическая стена с оконным вырезом → FCStd / STEP / PDF / SVG → тесты слоёв и пустот →
открытие в новом процессе → изменение отдельной копии → снимок и восстановление →
открытие восстановленной модели в новом процессе → независимое измерение контрольных пролётов PDF.

Каждая из пяти CAD-фаз получает новый процесс FreeCAD, отдельные настройки, идентификатор вызова и таймаут.
Исходная тестовая модель не перезаписывается. Подмена отчётов от другой фазы или коммита отклоняется.
Проверяются масштабы **конкретного синтетического примера**, а не любых будущих чертежей.

Текущий результат смотрите в [Actions](https://github.com/czm6zwd6dh-cmd/dom-freecad/actions/workflows/freecad-smoke.yml).
Успех должен относиться к проверенному полному SHA и попытке запуска. Наличие README не означает прохождение тестов.

## Файлы результата

Артефакт `freecad-synthetic-RUN_ID-ATTEMPT`: исходная/изменённая/восстановленная тестовые модели,
чертежи и previews, `qualification.json`, `unit-tests.json`, журналы каждого процесса, побайтовый snapshot,
а также `public-source.zip` с кодом данного коммита. Артефакты хранятся **3 дня**; нужные копии нужно сохранять отдельно.

## Границы

Не квалифицированы: реальные проекты R1, связанное изменение размеров и разрезов, DXF,
полное СПДС, профессиональный нормоконтроль, прочность и инженерная безопасность.
Отдельный закрытый маршрут для настоящего дома ещё не настроен.
Actions — не постоянный удалённый рабочий стол и не неограниченное резервное хранилище.
