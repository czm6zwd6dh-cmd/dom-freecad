# DOM-FreeCAD — открытые инструменты архитектурного проекта

Публичный репозиторий предназначен для инструментов **FreeCAD**, синтетических CAD-тестов и автоматизации с GitHub Actions. Основной проект дома R1 сюда **не загружается**.

## Конфиденциальность

Публичными являются весь Git-код, история, логи запусков и опубликованные артефакты Actions. **Запрещается** добавлять реальные планы, сканы, фотографии, координаты, адреса, обмеры, инженерные схемы, модели FCStd и персональные документы. Даже удалённые позже файлы могут остаться в истории Git.

## Этапы

1. Настроить стандартный бесплатный GitHub-hosted Ubuntu runner.
2. Проверить запуск FreeCAD 1.1.4, построение **синтетической** геометрии, создание FCStd и экспорт PDF.
3. Подключить и отдельно квалифицировать `architect-engineer-spds` v0.11.0.
4. Разработать безопасный закрытый канал для R1, не публикуя информацию о реальном здании.

**Статус:** инфраструктура создаётся. До успешных журналов GitHub Actions нативная работа FreeCAD не подтверждена. Оформление СПДС и строительство не считаются проверенными по синтетическим тестам.
