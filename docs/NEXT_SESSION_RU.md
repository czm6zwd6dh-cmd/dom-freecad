# Точка продолжения: публичная среда настроена

На 09.10.2026 завершена квалификация публичного синтетического CAD-маршрута.
Точная проверенная версия и доказательства находятся в `SETUP_CHECKPOINT.json`.
Не начинать установку FreeCAD с нуля только потому, что в текущем контейнере его нет.

## В начале нового сеанса

Прочитать актуальный полный скилл из файлов проекта, этот документ, `AGENTS.md`,
`OPERATIONS_RU.md`, `SETUP_CHECKPOINT.json`, затем получить фактический HEAD через
подключённый GitHub. Прочитать изменённые исходники по одному SHA. Сохранённый
чекпойнт — историческое доказательство, не разрешение игнорировать новые изменения.

Ведущий агент использует полный скилл v0.13.0. На runner установлены только
проверенные исполняемые модули из его `vendor`-поднабора. Нормативный реестр не
переоценивался этим CAD-тестом. Не утверждать, что весь скилл опубликован на GitHub.

Для расширенного цикла использовать `github-freecad-extended-profile.json`:

```bash
python scripts/github_freecad.py --profile /path/github-freecad-extended-profile.json \
  --run /path/run.json --jobs /path/jobs.json --artifacts /path/artifacts.json \
  --expected-sha FULL_REVIEWED_SHA --artifact-zip /path/original-artifact.zip
```

Старый профиль первого smoke-теста не требует новых шагов и потому недостаточен.
В полном скилле валидатор не выполняет сетевых запросов: run/jobs/artifacts нужно
заново получить через доверенный GitHub API, а не составить по памяти. Сверить
размер и digest исходного ZIP, повторить проверку CAD-отчётов и всех четырёх PDF.
Нельзя принимать зелёный статус тестов Python вместо нативного CAD-результата.

## Исправленная проблема

После открытия сохранённой модели проекция TechDraw могла оставаться старой,
хотя вырез в CAD-теле уже изменился. Текущий `export_page` обновляет источники
с сохранением самих видов, обрабатывает события и фиксирует native-view-geometry.
Контроль PDF проверяет отдельные линии, а не полагается на группировку путей.
В принятом результате изменение 1000 → 1200 мм дало ширину около 50 → 60 мм
на бумаге при 1:20; объём модели и экспорт согласованы для этого примера.

## Правила дальнейшей работы

Не перезаписывать чужие коммиты. После ошибки update_ref заново читать HEAD;
в этой настройке уже наблюдались параллельные изменения main. Не применять force.
Изменения, не прошедшие собственный нативный workflow, не подменяют принятую версию.

Реальные R1, сканы, адреса и инженерные схемы в этот публичный маршрут не подавать.
Следующая отдельная задача — закрытое хранение и выполнение для настоящего дома.
До её приёмки можно развивать и проверять только универсальные инструменты на
синтетических данных. Ассоциативные размеры, разрезы, DXF, полное СПДС и решения
для строительства требуют отдельной квалификации.

Артефакты Actions хранятся 3 дня. Чекпойнт и исходники в Git не продлевают этот
срок. Нужный исходный ZIP результатов и пакет восстановления сохранить отдельно.
