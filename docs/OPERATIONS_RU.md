# Работа с телефона и восстановление среды

## Нормальный запуск

Агент читает актуальный полный скилл и исходники GitHub по одному SHA, готовит только
синтетическое изменение, проверяет diff и публикует согласованный коммит.
`push` в `main` запускает workflow; есть и ручной `workflow_dispatch` без расписания.
На iPhone: страница репозитория → Actions (в узком меню может быть More) →
FreeCAD 1.1.4 native synthetic smoke → Run workflow → main → Run workflow.
Ни GitHub Copilot, ни постоянно открытый компьютер не требуются для этого пакетного маршрута.

Стандартный публичный GitHub-hosted runner не следует называть безлимитным компьютером.
Workflow ограничен 30 минутами; каждый вызов CAD — 240 секундами плюс завершение процесса.
Новый запуск той же ветки может отменить предыдущий через concurrency.

## Приёмка результата

Проверить полный head_sha, run_id и run_attempt, успешность каждого обязательного шага,
имя/срок/размер/SHA-256 артефакта. Сохранить именно исходные байты ZIP, не перепакованный каталог.
Метаданные читать через подключённый GitHub, не считать синтетический JSON доказательством API.
Проверять `qualification.json`, `unit-tests.json` и пять фаз:
`report.json`, `cold-reopen.json`, `mutate.json`, `native-tools.json`, `restore-reopen.json`.

Из полного скилла `scripts/github_freecad.py` связывает внешние API run/jobs/artifacts с SHA
и опционально проверяет ZIP. Расширенный профиль должен перечислять все новые шаги workflow;
старый профиль первого smoke-теста не квалифицирует расширенную цепочку.
Валидатор метаданных сам по себе не проверяет CAD.

После безопасной распаковки выполнить `ci/check_extended.py RESULT_DIR --expected-sha SHA`
из `public-source.zip` того же коммита, предварительно проверив его код.
Открыть **все четыре** PDF/preview: первоначальный, cold, mutated, restored-proof.
На изменённом листе вырез шире; остальные параметры исходника сохранены.
Часть текста FreeCAD может экспортировать контурами: извлечение текста не заменяет
визуальную проверку кириллицы, наложений и обрезки. Масштабы контролируются по векторным
прямоугольникам; допуск 0.2 мм относится к бумаге, не к точности обмеров здания.

## Что сохранять

Артефакты Actions удаляются по сроку хранения (здесь 3 дня). Сохранить нужный ZIP отдельно.
`backup/` — проверенный снимок закрытого синтетического комплекта, `restored/` — его
восстановленная побайтовая копия. Успешный native reopen — отдельный отчёт, не изменение
исторического `snapshot.json`. Снимок в том же runner не доказывает внешнюю долговечность.
`public-source.zip` позволяет восстановить точные публичные исходники и настройки.

## Сбой

403: проверить доступ приложения, не публиковать токены. Checksum mismatch: остановиться,
не подменять ожидаемый hash фактически скачанным. Ошибка Qt/xcb: изучить текущие зависимости
и лог конкретной фазы. Timeout/crash: сохранить журнал, исправить причину, сделать один новый
запуск. Cancelled: проверить более новый запуск concurrency, не считать это CAD-ошибкой.
Не отключать проверки ради зелёного статуса. Не смешивать артефакты разных попыток.

## Подключение настоящего дома

Этот маршрут намеренно не принимает произвольный путь/URL к модели. Реальные R1, сканы,
чертежи, обмеры и инженерные схемы запрещены даже как временные входы публичного Actions.
До работы с ними нужен отдельно согласованный и проверенный закрытый маршрут, включая
хранилище, права, журналы, выходные файлы и резервные копии. Его наличие нельзя вывести
из успешного публичного smoke-теста.
